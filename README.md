# Presentación de Tecnologías 🚀

Una presentación interactiva sobre las tecnologías más importantes de la era digital.

## Contenido

Esta presentación cubre los siguientes temas:

- 💡 Introducción a las Tecnologías Modernas
- 📚 Evolución Histórica de la Tecnología
- 🤖 Inteligencia Artificial y Machine Learning
- ☁️ Cloud Computing
- 🔗 Internet de las Cosas (IoT)
- ⛓️ Blockchain y Criptomonedas
- 🌍 Impacto en la Sociedad
- 🔮 Tendencias Futuras
- ✅ Conclusiones

## Cómo Ver la Presentación

### Opción 1: Navegador Local

1. Clona este repositorio:
   ```bash
   git clone https://github.com/hojitosiap-lab/presentacion-tecnologias.git
   ```

2. Abre el archivo `index.html` en tu navegador web favorito

### Opción 2: GitHub Pages

La presentación está disponible en línea (si GitHub Pages está habilitado):
```
https://hojitosiap-lab.github.io/presentacion-tecnologias/
```

## Personalización

Puedes personalizar la presentación editando el archivo `index.html`:

- Modifica los estilos CSS en la sección `<style>`
- Añade o elimina diapositivas (elementos `<div class="slide">`)
- Cambia el contenido según tus necesidades
